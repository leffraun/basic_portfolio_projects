# Basic Portfolio Projects

The following repository is a list of my projects that I have coded using python (html/css for the portfolio project only).

## list

  The following are the list of projects to be added or already added into my basic portfolio projects repository:
    * File organiser 
    * Password generator
    * Expense Tracker
    * weather CLI 
    * Data Analyser
    * Portfolio Website (ongoing)

  ### File organiser

  This is a file organiser coded in python where inside the main folder, the user is asked to input new files into it. 
  
  * Once the files are added, new folders are created based on the extensions of the given files.
  * If file has no extension, it is sent to a folder called 'others'

### Password generator

  I have created two versions of the password generator - one a simple code that is easy to understand but easy to find error in, and another that uses cli to
  choose how you want your password- default with 12 to 15 characters with symbols and digits, choosing a number of digits, symbols or numbers. 

### Expense Tracker

  Using the csv library, I have created a csv using user input and based on that, the expense is tracked. The total is displayed based on the grand total and the 
  individual total.

### Weather API cli

  With a simple api, I have developed a weather api cli program that provides the weather of the place based on the place given by the user in the terminal.
  If the place does not exist, error occurs.

### Data Analyser

  Using Pandas for creating and reading csv and matplotlib to plot the graph, I have set up a data analyser to find the maximum, minimum, average and the most and 
  least of the given users.

### Portfolio Project

  A project to display all the aforesaid programs into one and demonstrates my front end skills. Coming soon.
